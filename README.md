## 🚀 Ejecutar Localmente

### Prerequisitos
- Node.js 18+ 
- npm o yarn

### Instalación

1. **Clonar el repositorio**
   ```bash
   git clone https://github.com/jualvara/jualvara.github.io.git
   cd jualvara.github.io
   ```

2. **Instalar dependencias**
   ```bash
   npm install
   ```

3. **Ejecutar en modo desarrollo**
   ```bash
   npm run dev
   ```

4. **Abrir en el navegador**
   ```
   http://localhost:3000
   ```

### Build para producción

```bash
npm run build
```

Los archivos optimizados se generan en la carpeta `dist/`.
